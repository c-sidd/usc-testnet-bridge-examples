# 04 — Use Cases

The following candidates are being evaluated for the final hackathon implementation. Do not implement all of them; select one primary flow.

## 1. AI DeFi Risk Agent

```text
Source-chain financial event
        |
        v
Attestcoin verification
        |
        v
AI risk analysis
        |
        v
Risk decision
        |
        v
Creditcoin contract action
```

Potential demo: a verified event changes a user's risk state and the application reacts according to predefined rules.

## 2. Cross-Chain Lending Agent

A source-chain event representing collateral or another lending-related action is verified on Creditcoin. The AI evaluates application conditions and proposes or triggers a lending action.

## 3. Autonomous Treasury Agent

Verified source-chain events become inputs to an AI treasury strategy. The agent evaluates predefined conditions and requests a rebalancing action on Creditcoin.

## Selection Criteria

Choose the final use case using:

- Clear Attestcoin usage.
- Simple end-to-end testnet demonstration.
- Strong AI component without making the AI the trust boundary.
- Small enough scope for the ideathon timeline.
- Easy-to-understand judge narrative.
- Visible on-chain result.
